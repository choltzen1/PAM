# Shared Component Inventory

This is a lightweight index of shared UI components and where their styles live.

## Buttons
- Location: `static/css/global.css`
- Classes: `btn`, `btn-magenta`, `btn-outline`, `btn-admin` (legacy)

## Forms
- Location: `static/css/global.css`
- Classes: `form-control`, `form-select`

## Tables
- Location: `static/css/global.css`
- Classes: `table` (striping/headers)

## Alerts / Toasts
- Location: `static/css/global.css` (preferred)
- Rule: use component classes + state modifiers (no JS inline styling)

## Layout primitives
- Location: `static/css/styles.css`
- Classes: `body-fixed-header-footer`, `app-main-scroll`, utilities
